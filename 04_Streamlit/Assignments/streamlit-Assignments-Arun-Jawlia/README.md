Used

## How To Run
1. UnZip the current folder `Streamlit-Assignments-Arun-Jawlia`
2. `pip install streamlit`
3. Run file one by one 
   1. `streamlit 1_app_basic.py`
   2. `streamlit 2_app_discount.py`
   3. `streamlit 3_app_product_form.py`
   4. `streamlit 4_app_dashboard.py`
