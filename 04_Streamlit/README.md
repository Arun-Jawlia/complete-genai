# Streamlit 

This project is a beginner-friendly Streamlit application that demonstrates:

- Streamlit Fundamentals
- User Input Widgets
- Layout & UI Design
- Session State
- Data Handling

---

### Requirements
1. python 3+


### Install Streamlit
```
pip install streamlit
```


### Run the Application: Open terminal in the project folder and run:
```
streamlit run app.py
```

### Project Structure

```text
project/
│
├── app.py
└── README.md
```
